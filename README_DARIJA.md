# بوت تحميل TikTok و Instagram — شرح بالدارجة

## شنو كيدير هاد البوت؟
المستخدم كيصيفط رابط فيديو TikTok ولا Instagram، البوت كيحملو وكيصيفطو ليه في تيليغرام.
TikTok كيرجع بلا علامة مائية إلا كانت متاحة.

فيه:
- حد مجاني: 10 في النهار (تقدر تبدلو في `.env`)
- مكان للإعلان بعد كل فيديو
- مكان لقناة إجبارية باش تكبر القناة ديالك

## الخطوة 1: جيب التوكن من BotFather (5 دقايق)

1. حل تيليغرام، قلب على `@BotFather`
2. صيفط ليه `/newbot`
3. غادي يسولك على سمية البوت، مثلا: `TikTok Downloader`
4. من بعد يسولك على username، خاصو يسالي بـ `bot`، مثلا: `tiktok_dl_2026_bot`
5. غادي يعطيك توكن طويل بحال هادا: `123456:ABC-DEF...`
   **هاد التوكن سري، ما تصيفطوش لشي واحد.**

## الخطوة 2: شغل البوت في السيرفر

البوت خاصو يبقى خدام 24/24. ما يخدمش مزيان غير من التيليفون حيت غادي يطفى.

### أسهل طريقة للتجربة (في Termux ولا الكمبيوتر):

```bash
# نزل الملفات، ودخل للمجلد
cd telegram-downloader-bot

# ثبت المكتبات
pip install -r requirements.txt

# صاوب ملف .env
cp .env.example .env
# حل .env وبدل BOT_TOKEN بالتوكن ديالك

# شغل البوت
python bot.py
```

إلا شفت `✅ البوت خدام...` راه خدام. مشي لتيليغرام، قلب على البوت ديالك، دير `/start`، صيفط رابط TikTok.

### للتشغيل الدائم: Render (مجاني في البداية)

1. حط الكود في GitHub
2. دخل لـ render.com، دير New > Background Worker
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. زيد Environment Variable: `BOT_TOKEN` = التوكن ديالك
6. دير Deploy

ملاحظة: Render المجاني كيطفى إلا ما كانش فيه استعمال، من بعد خاص VPS رخيص (حوالي 5$ في الشهر) باش يبقى خدام ديما.

## الخطوة 3: الإعلانات والربح

### 1. قناة إجبارية (أحسن بداية)
في `.env`:
```
FORCE_CHANNEL=mychannel
```
بدل `mychannel` بسمية القناة ديالك بلا `@`.
من بعد أي واحد بغا يحمل خاصو يشترك في قناتك أولا. القناة كتكبر، ومن بعد تقدر:
- تبيع بوست إعلاني في القناة
- تفعل Telegram Ads إلا وصلتي 1000 مشترك

### 2. إعلان بعد كل فيديو
في `.env`:
```
AD_TEXT=اشترك في قناتنا للمزيد 👇
AD_BUTTON_TEXT=اشترك دابا
AD_BUTTON_URL=https://t.me/mychannel
```
هاد الإعلان غادي يتبعت مع كل تحميل.

### 3. بريميوم (من بعد)
دابا الحد هو 10 في النهار. من بعد تقدر تزيد:
- اللي بغا بلا حدود يخلص بـ Telegram Stars
- ولا تبيع اشتراك شهري

ما ديرش بريميوم من الأول، حتى يكبر البوت ويوليو الناس كيستعملوه بزاف.

## مشكل Instagram

Instagram ولا كيطلب تسجيل دخول بزاف ديال المرات في 2026.
- الفيديوهات العامة (Public) كتخدم عادة.
- إلا ما خدمش، خاص ملف `cookies.txt`:
  1. في الكمبيوتر، ثبت إضافة `Get cookies.txt LOCALLY` في Chrome
  2. دخل لـ instagram.com من نفس المتصفح
  3. خرج ملف cookies.txt وحطو حدا `bot.py`
  4. عاود شغل البوت

TikTok خدام عادة بلا كوكيز.

## حدود لازم تعرفها

- تيليغرام ما كيسمحش للبوت يصيفط فيديو فوق 50MB. البوت ديالنا كيرفض فوق 48MB.
- ما تحملش أفلام ومسلسلات وموسيقى محمية، البوت يقدر يتحظر.
- yt-dlp كيتبدل مع حماية المواقع، إلا وقف التحميل شي نهار، خاص تحديث: `pip install -U yt-dlp`

## شنو خاصك دابا؟

1. جيب التوكن من @BotFather
2. صيفطو ليا؟ **لا، ما تصيفطش التوكن في الشات.** حطو في `.env` في السيرفر ديالك.
3. جرب البوت برابط TikTok، وقول ليا واش خدم ولا لا، باش نصلحو المشكل إلا كان.
